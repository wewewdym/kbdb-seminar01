# Семинар 1 — Базы знаний и базы данных

Практическая работа: PostgreSQL в Docker, исследование учебной БД компрессорных станций и запросы SQL.

## Запуск

Нужны Docker Desktop (или Docker Engine с Compose) и make.

```bash
docker compose up -d
docker compose ps
make run
```

Подключение к БД: `make psql`. Сброс данных: `make reset` (удаляет локальный Docker-том).

## Состав

- `docker-compose.yml`, `Makefile` — запуск контейнера и SQL.
- `sql/init/01_schema.sql`, `02_data.sql` — неизменённые исходные схема и данные преподавателя.
- `sql/seminar01.sql` — анализ данных, решения обязательных задач 1–7 и дополнительных 8–11.
- `DEFENSE.md` — подготовка к показу работы преподавателю.

## Наблюдения о данных

В учебном датасете три станции, семь агрегатов, 18 датчиков, 24 462 измерения, 26 событий и 11 ремонтов. Точные результаты проверяются запросами в начале `sql/seminar01.sql`. Значения `severity` не унифицированы: `alarm` и `Alarm`, `warning` и `warning ` (пробел в конце). Датчик `TE-999` без измерений, агрегат `GPA-4` без датчиков. Ремонты GPA-2 с ID 1, 2, 3 — возможные дубли, которые нельзя удалять без проверки.

Для поиска агрегатов без аварий применено `LOWER(TRIM(severity))`.

**Проверка:** решение подготовлено по SQL-схеме, но фактический запуск Docker и `make run` необходимо выполнить на компьютере.
